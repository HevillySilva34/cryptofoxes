# CryptoFoxes — responsive recreation

Projeto estático em HTML, CSS e JavaScript, inspirado na imagem de referência.

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
3. É necessário internet para carregar Google Fonts e GSAP via CDN. Sem internet, o layout continua funcional, usando fontes de fallback.

## Estrutura
- `index.html`: estrutura e conteúdo
- `styles.css`: identidade visual, layout e breakpoints responsivos
- `script.js`: interação do botão e animações GSAP/ScrollTrigger
- `assets/`: recortes de pixel art extraídos da imagem fornecida

## Personalização
Substitua os arquivos em `assets/` pelas imagens originais em maior resolução, caso estejam disponíveis. Os textos e links também podem ser editados diretamente no HTML.
